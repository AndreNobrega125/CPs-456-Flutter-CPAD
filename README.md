# CPs-456-Flutter-CPAD

##Proposta

Problema: estudantes universitários têm dificuldade de controlar gastos pessoais e organizar despesas compartilhadas (contas de casa, saídas em grupo, rachar delivery/Uber) — normalmente resolvido de forma manual, via planilha ou "fiado" sem registro.

Público-alvo: estudantes universitários, moradores de república/kitnet, com renda limitada (mesada, estágio, bolsa) que dividem gastos com colegas com frequência.

MVP (funcionalidades mínimas):

Controle financeiro pessoal (registrar receitas/gastos, categorias)
Split de contas entre grupo de amigos (quem deve pra quem)
Metas de economia (definir meta, acompanhar progresso)
Visão consolidada ("carteira") do saldo pessoal + pendências de split
